# ESP32_HBH

Прошивка для платы **ESP32-WROOM-32D**. 
Проект собран — на чистом **C** через официальный фреймворк **ESP-IDF v6.1** с использованием **FreeRTOS**. 

## 🚀 Как это работает
1. Плата инициализирует стек Wi-Fi и поднимает собственную точку доступа (`HAPPY_BIRTHDAY`).
2. При подключении телефона и переходе на IP-адрес платы, асинхронный веб-сервер отдает кастомную HTML-страницу.
3. Браузер на телефоне запускает встроенный **8-битный синтезатор звука (Web Audio Context)**.
5. Нажатие на кнопку отправляет `POST`-запрос на плату, и отдельный поток FreeRTOS начинает бешено мигать светодиодом через прямую запись битовых масок в регистры `GPIO_ENABLE_REG` и `GPIO_OUT_REG`.

## 🛠️ Архитектура проекта
* `app_main`: Точка входа. Инициализирует NVS-память, запускает Wi-Fi стек и стартует потоки.
* `HTTP Server`: Демон, который слушает порты и асинхронно обрабатывает запросы от смартфона.
* `led_party_task`: Низкоприоритетная FreeRTOS-задача, которая крутится на втором ядре и управляет физическим пином светодиода.

## 🔧 Как развернуть и прошить
1. Открыть проект в **VS Code** с установленным плагином **ESP-IDF v6.1**.
2. Переключить терминал на `ESP-IDF Terminal`.
3. Задать целевой чип:
   ```bash
   idf.py set-target esp32
   ```
4. Собрать проект:
   ```bash
   idf.py build
   ```
5. Перевести плату в режим загрузчика (зажать кнопку **BOOT**, кликнуть **EN/RST**, отпустить BOOT) и залить прошивку (заменить `COM3` на целевой):
   ```bash
   idf.py -p COM3 flash monitor
   ```
## 🔌 Подключение периферии
* **GPIO 2:** Сюда подключается анод (длинная нога) светодиода. Катод — через резистор 1кОм на `GND` или `+3v3`.
* **Wi-Fi сеть:** `HAPPY_BIRTHDAY` (Пароль: `12345678`)
* **Адрес в браузере:** `http://192.168.4.1`
